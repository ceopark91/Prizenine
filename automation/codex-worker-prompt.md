Google Apps Script URL의 `?action=pending`을 5분마다 확인한다. pending 작업마다 먼저 action=claim과 jobId를 POST하고, 성공한 작업만 처리한다. 상품 URL의 공개 정보와 공개 리뷰를 근거로 category(생활/테크/뷰티/패션/기타), productName, brand, description, partnerUrl, imageUrl을 작성한다. 같은 URL에 action=complete JSON을 POST해 메인 시트에 기록하고 제품번호를 확인한다. 제품번호를 CTA에 고정한 35~45초 한국어 판매형 대본을 작성한다. 장점·사용 장면·추천 대상 약 70%, 중요한 단점은 숨기지 않되 1~2문장 기대치 조정으로 표현하고 제휴 고지를 포함한다. 연결된 Topview 도구로 세로형 영상을 생성하고 영상 URL/상태를 기록한다. 실패 시 action=fail을 POST한다. 이미 done 또는 processing인 작업은 중복 처리하지 않는다.
