# PrizeNine 자동 영상 작업자 지침

최종 사업 목표는 시청자가 광고 리뷰 영상을 본 뒤 프로필 링크로 이동하고, 영상에서 안내한 제품번호를 검색해 해당 상품을 구매하여 리워드가 발생하도록 만드는 것이다. 단순 영상 생성이나 캐릭터 소개 영상은 완료가 아니다.

공식 Google Apps Script 엔드포인트: https://script.google.com/macros/s/AKfycbxv3e34upUDpF315N7M5hhsn8MR0c6OG91cMyctEiMxmkg3KNQMiWw9zvePNFImOOrMPg/exec

## 최우선 강제 규칙: 제품번호 선확정

제품번호 선확정은 테스트·정식 자동화 모두에 적용되는 첫 번째 관문이다. pending 작업을 claim한 직후 Google 시트 상품목록의 마지막 실제 제품번호 다음 번호를 계산해 큐 행의 제품번호 칸에 기록하고, 다시 읽어 값이 저장된 것을 확인한다. 이 확인 전에는 상품 페이지 열기, 상품 분석, 대사 작성, 음성 생성, 이미지 생성, 영상 생성, 자막 작성, CTA 작성, `complete` 호출을 절대 수행하지 않는다. 제품번호 칸이 비어 있거나 마지막 번호를 읽을 수 없으면 즉시 `failed`로 기록하고 중단한다. 확정한 동일 번호를 대사·음성·자막·CTA·시트 등록에 끝까지 사용하며, 실패한 번호는 폐기한다.

최신 Google Apps Script 주소의 `?action=pending`을 확인하고, pending 작업은 먼저 `action=claim`으로 확보한다. GS에 별도 번호 예약 기능을 추가하지 않는다. 작업 시작 시 코덱스가 연결된 Google 시트의 상품목록에서 마지막 실제 제품번호를 브라우저로 확인해 다음 번호를 작업 메모에 매핑하고, 한 번에 하나씩 순차 처리한다. 매핑한 번호를 음성·자막·CTA와 최종 시트 등록에 동일하게 사용한다. 상품 URL을 실제 브라우저로 열어 상품명·브랜드·설명·가격·공개 리뷰와 실제 상품 이미지 2~4장을 확보한다. 원본 이미지가 세로로 길면 제품 외형을 재생성하지 말고 원본 픽셀을 기계적으로 패딩/리사이즈한다.

## 판매 영상 구성

- 기본 길이: 30~45초. 15초는 명시적인 테스트 모드일 때만 허용한다.
- 1막 후킹(0~3초): 제품이 해결하는 불편이나 문제를 즉시 보여주는 강한 장면과 한 문장.
- 2막 제품 설명·장점(약 3~25초): 실제 상품 정면·디테일·구성품·핵심 기능·사용 전후를 보여준다. 제품 사용이 돋보이는 장면을 우선하며 인물 출연은 필수가 아니다.
- 3막 단점·추천 대상(약 25~35초): 구매 전에 알아야 할 간단하고 사실적인 단점 한 가지와 `이런 사람에게 딱이다`라는 추천 대상을 안내한다.
- 4막 CTA(마지막 4~6초): `관심 있으신 분은 프로필 링크에서 제품번호 N번을 검색해 보세요`를 화면과 음성으로 정확히 표시하고 제휴 고지를 포함한다.

전체 영상을 한 번에 생성하지 않는다. 먼저 위 각 막과 세부 장면에 사용할 세로형 기준 이미지를 개별 제작한다. 모든 기준 이미지는 실제 상품 원본을 참조해 색상·형태·로고·부품·크기 비율을 일관되게 유지한다. 승인 가능한 기준 이미지만 각각 3~6초 image-to-video 클립으로 변환한 뒤, 확정된 음성 타임라인에 맞춰 순서대로 이어 붙인다. 자막과 CTA 글자는 영상 생성 이미지에 넣지 않고 최종 편집 단계에서 선명한 오버레이로 추가한다.

캐릭터 시트(정면·측면·전신 자료)는 생성 참고자료일 뿐이며 원본을 영상 배경이나 본편 화면으로 노출하지 않는다. 캐릭터는 실제 상품을 들거나 가리키는 진행자 장면 또는 짧은 오버레이로만 사용한다. 영상의 중심은 실제 상품 이미지, 디테일, 사용 장면, 문제 해결 전후 비교와 구성품이어야 한다. 캐릭터만 말하고 제품이 보이지 않는 아바타 영상은 실패 처리한다.

사용자가 별도 보이스를 지정하지 않으면 탑뷰 대표 한국어 여성 보이스 중 20대·발랄한 UGC 톤을 사용한다. 음성을 먼저 확정한 뒤 그 오디오 기준으로 립싱크 영상을 만든다. 한글 자막은 영상 생성 후 음성에서 자동 생성하고 오탈자·타이밍을 수동 검수한다.

Topview Canvas에서는 실제 상품 이미지 여러 장과 고정 캐릭터를 함께 참조해 image-to-video로 생성한다. text-to-video로 제품 외형을 추정하지 않는다. 킬링 인서트는 상품을 구매하고 싶게 만드는 구체적 사용 장면(문제 발생→제품 사용→개선)을 우선한다. 영상 파일과 결과 URL을 검증한 뒤에만 Apps Script `action=complete`를 호출하고, 실패 시 `action=fail`과 원인을 기록한다.

## 완료 전 필수 검수

- 실제 제품이 영상 대부분에서 식별 가능하게 보인다.
- 캐릭터 시트 원본이 영상에 노출되지 않는다.
- 제품의 핵심 장점과 사용 결과가 시각적으로 설명된다.
- 20대의 밝고 발랄한 한국 여성 음성을 사용한다.
- 음성, 필요한 립싱크 장면, 자막 타이밍이 일치한다.
- `프로필 링크`와 정확한 `제품번호 N번` 안내가 음성과 자막에 모두 포함된다.
- 모바일에서 바로 재생 가능한 영상 URL이 확보된다.

위 항목 중 하나라도 실패하면 `action=complete`를 호출하지 않고 수정하거나 실패 원인을 기록한다.

## 크기·비율 정확성

상품 상세페이지의 상품정보·옵션·배송/규격 영역에서 가로×세로×높이, 무게, 용량 등 치수 정보를 먼저 추출해 작업 기록과 영상 프롬프트에 전달한다. 실제 가로·세로·높이 비율과 손, 책상, 냉장고 등 주변 기준물과의 상대 크기를 유지한다. 제품을 실제보다 크게 보이게 하거나 작게 축소하지 않는다. 상세페이지에 치수가 없으면 임의로 추정하지 말고 `치수 확인 불가`로 기록하며 과장된 원근·클로즈업을 피한다. 모델이 제품을 들거나 사용하는 장면에서도 손 크기와 제품 비율이 장면마다 일관되게 유지되어야 한다.
