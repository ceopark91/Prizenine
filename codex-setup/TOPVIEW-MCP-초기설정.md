# Topview MCP 초기 설정 절차

초기 설정 도우미는 먼저 Topview MCP 연결 여부를 확인합니다.

## 이미 연결된 경우

`get_topview_canvas_state` 조회가 성공하면 설치를 다시 진행하지 않고 다음 단계로 넘어갑니다.

## 연결되지 않은 경우

도우미가 다음처럼 사용자에게 묻습니다.

> Topview MCP가 연결되지 않았습니다. 설치와 로그인 안내를 진행할까요?

사용자가 `예`라고 답하면:

1. Topview Skill/MCP 설치 안내를 엽니다.
2. 사용자가 Topview 로그인과 OAuth 인증을 완료합니다.
3. 도우미가 Canvas 조회를 다시 시도합니다.
4. 연결 성공 후 Canvas·캐릭터 설정으로 진행합니다.

사용자가 `아니오`라고 답하면 영상 자동화를 시작하지 않고 설정을 중단합니다.

## 권한 안내

Topview 로그인과 OAuth 승인 버튼은 사용자 계정 권한이 필요하므로 사용자가 직접 한 번 승인해야 합니다. 승인 이후 Canvas 조회, 캐릭터 생성, 설정 저장은 자동으로 진행합니다.
