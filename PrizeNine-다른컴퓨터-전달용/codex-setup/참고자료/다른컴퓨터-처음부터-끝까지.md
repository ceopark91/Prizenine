# PrizeNine 다른 컴퓨터 설치 길라잡이

처음 보는 사람도 이 문서 순서대로만 진행하면 됩니다.

## 1. 준비

1. `탑뷰프로젝트` 폴더를 컴퓨터에 복사합니다.
2. Codex Desktop을 설치하고 로그인합니다.
3. PowerShell 또는 Codex 터미널을 엽니다.

## 2. Topview MCP 설치

아래 세 줄을 한 줄씩 실행합니다.

```bash
codex plugin marketplace add https://github.com/topviewai/plugins --ref main --json
codex plugin add topview@topview --json
codex mcp login topview
```

세 번째 명령을 실행하면 브라우저가 열립니다. Topview에 로그인하고 OAuth 허용을 누릅니다.

설치 확인:

```bash
codex plugin list --json
codex mcp get topview --json
```

오류가 나면 설치를 반복하지 말고 오류 화면을 저장해 관리자에게 보냅니다.

## 3. Google Apps Script 연결

1. 상품목록 Google Sheet를 엽니다.
2. `확장 프로그램 → Apps Script`를 누릅니다.
3. 기존 코드를 전부 지웁니다.
4. 프로젝트 폴더의 `docs/google-apps-script.gs` 전체를 붙여넣습니다.
5. 저장합니다.
6. `배포 → 새 배포 → 웹 앱`을 선택합니다.
7. 실행 사용자: 본인
8. 액세스 권한: 모든 사용자
9. `/exec` 주소를 복사합니다.

## 4. 초기 설정 파일

`codex-setup/사용자-설정만-수정.md`를 복사해 `CONFIG.local.md`로 저장합니다.

다음 세 곳만 입력합니다.

```text
GOOGLE_FORM_URL=본인_구글폼_주소
SHEET_URL=본인_구글시트_주소
NOTIFY_EMAIL=알림받을_이메일
```

그리고 `GOOGLE_APPS_SCRIPT_URL`에 3단계에서 복사한 `/exec` 주소를 넣습니다.

## 4-1. GitHub와 Vercel 배포

### GitHub

1. GitHub에 로그인합니다.
2. PrizeNine 저장소를 엽니다.
3. `Code → Codespaces`가 아니라 저장소 주소를 복사합니다.

### Vercel

1. [Vercel](https://vercel.com)에 로그인합니다.
2. `Add New → Project`를 누릅니다.
3. GitHub 저장소를 선택하고 `Import`합니다.
4. 프로젝트 이름은 원하는 이름을 사용합니다.
5. `Environment Variables`에 아래 값만 입력합니다.

```text
GOOGLE_APPS_SCRIPT_URL=사용자_Apps_Script_exec_주소
```

`TRIGGER_SECRET`과 `INGEST_TOKEN`을 사용하는 프로젝트라면 Vercel에 같은 이름으로 사용자별 비밀키를 추가합니다. 값은 GitHub에 올리지 않습니다.

6. `Deploy`를 누릅니다.

배포가 끝나면 Vercel 주소를 열어 상품목록이 표시되는지 확인합니다. 사용자가 바꾸는 핵심 값은 자신의 Apps Script 주소와 Google Sheet 연결값입니다. 코드는 수정하지 않습니다.

## 5. Topview 초기 설정

Codex에서 다음이라고 입력합니다.

```text
설정 시작
```

Topview Canvas를 모르면 새 Canvas를 만들도록 답합니다. 원하는 캐릭터 외형도 문장으로 입력합니다.

예:

```text
30대 한국 여성, 밝고 신뢰감 있는 생활용품 리뷰어, 단정한 단발
```

Topview가 캐릭터 생성을 요청하면 크레딧 사용 여부를 확인한 뒤 승인합니다.

## 6. 실행 테스트

`codex-setup/START-HERE.bat`을 더블클릭합니다.

상품 주소를 입력하면 자동으로:

1. 상세페이지 이미지 3~6장 수집
2. 공개 리뷰와 상세설명 분석
3. 모델과 실제 사용 상황 중심 콘티 작성
4. 제품 이미지 레퍼런스 기반 영상 생성
5. 제품번호 CTA 삽입
6. Google Sheet 저장
7. 이메일·Codex 알림

마지막 문구는 자동으로 다음 형식입니다.

```text
제품이 궁금하시면 프로필 상세 링크에서 {제품번호}번을 검색해보세요.
```

## 7. 보안

`CONFIG.local.md`와 `.env.local`은 API 키와 계정 정보가 들어갈 수 있으므로 GitHub에 올리지 않습니다.
