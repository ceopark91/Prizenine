# 공통 마켓 리뷰 수집 정책

쿠팡·Temu·AliExpress 등 모든 마켓플레이스는 동일한 수집 순서를 사용한다.

1. 공식 API 또는 허용된 공개 데이터 경로를 먼저 확인한다.
2. 서버의 공개 HTML/JSON-LD 요청을 시도한다.
3. 403, WAF, 봇 확인 또는 동적 렌더링으로 실패하면 사용자 브라우저의 공개 상품 페이지로 전환한다.
4. 브라우저에서 실제로 보이는 상품 정보와 리뷰 DOM만 읽는다.
5. 공개 리뷰가 보이면 리뷰별 원문·평점·날짜·근거를 분석 API로 전달한다.
6. CAPTCHA, 로그인 요구, 접근 차단 화면이면 자동 해결·우회하지 않고 해당 작업을 중단한다.

## 마켓플레이스 Adapter 계약

모든 Adapter는 다음 결과 중 하나를 반환한다.

```json
{
  "mode": "server-public | browser-session | approved-api",
  "status": "ready | blocked | no_reviews",
  "product": {},
  "reviews": [],
  "reason": ""
}
```

`browser-session`은 사용자가 로그인하지 않은 상태에서 공개적으로 보이는 데이터만 포함한다. 작성자 식별자, 연락처, 쿠키, 토큰, 구매 내역은 수집하지 않는다.

## 영상 자동화 연결

리뷰 수집 결과가 `ready`일 때만 스토리보드를 만든다. 장점과 구매 전 확인사항을 함께 넣고, 단일 리뷰를 전체 의견처럼 표현하지 않는다. `blocked` 또는 `no_reviews`이면 영상 생성은 보류하고 `complete`를 호출하지 않는다.
