# PrizeNine 초기 설정 동작

사용자가 `세팅해`, `초기설정해`, `설정 시작`, `처음부터 설정` 중 하나를 입력하면 다음 문서를 먼저 읽고 설정 도우미를 시작한다.

1. `codex-setup/다른컴퓨터-처음부터-끝까지.md`
2. `codex-setup/TOPVIEW-MCP-초기설정.md`
3. `codex-setup/사용자-설정만-수정.md`
4. `docs/google-apps-script.gs`

Topview MCP 연결 여부를 먼저 확인한다. 연결되지 않았으면 설치·OAuth 진행 여부를 한 문장으로 묻고, 승인받은 경우에만 공식 설치 절차를 진행한다. 초보자에게 여러 값을 한꺼번에 요구하지 않는다. 다음 질문을 한 번에 하나씩 하고, 매번 어디를 클릭해 무엇을 복사하는지 한국어로 설명한다: (1) Google Form 주소, (2) Google Sheet 주소, (3) 알림 이메일. 사용자가 모르는 항목은 직접 찾도록 안내하고 전문 용어를 쓰지 않는다. Vercel 환경변수도 이름을 먼저 보여주지 말고 필요한 값을 질문형으로 받는다. Canvas를 모르면 새로 만들고, 캐릭터 설명을 받으면 Topview에서 캐릭터 생성 여부를 확인한 뒤 적용한다. 모든 설정을 저장한 후 최근 상품 주소로 테스트하고 결과를 보고한다.

비밀값을 출력하거나 GitHub에 커밋하지 않는다. 사용자의 명시적 승인 없이 유료 생성, 배포, 외부 메시지 전송을 실행하지 않는다.
