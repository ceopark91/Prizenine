# 다른 컴퓨터 설치 순서

1. Codex와 Topview 플러그인을 설치하고 같은 계정으로 로그인합니다.
2. `CONFIG.template.md`를 `CONFIG.local.md`로 복사합니다.
3. 자신의 Form, Sheet, Apps Script, Topview Canvas 주소와 알림 이메일을 입력합니다.
4. 쿠팡·테무·알리 상품 페이지가 PC 브라우저에서 열리는지 확인합니다.
5. `START-HERE.bat`을 더블클릭합니다.
6. Google Form에 상품 URL을 입력합니다.

자동화 순서:

```text
URL 접수 → claim → 브라우저 상품·리뷰 조사 → 실제 상품 이미지 확보
→ 명예모델1호 + 상품 이미지 image_to_video → 영상 성공 확인
→ complete → 상품목록 등록 → 이메일 알림
```

이미지 확보 또는 영상 생성 실패 시 상품목록에 등록하지 않고 `failed` 처리합니다.
