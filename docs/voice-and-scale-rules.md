# 공용 음성·크기 자동화 규칙

이 문서는 PC나 Codex 작업이 바뀌어도 동일하게 적용하는 운영 규칙입니다.

## 음성 발음

TTS에는 `120cm`, `12W`, `220V` 같은 원문 표기를 직접 넣지 않습니다. 콘티마다 음성용 `spoken_ko`와 화면용 `caption_text`를 분리합니다.

예:

- 음성: `백이십 센티미터`
- 자막: `120cm`

숫자·단위·수량·상품번호도 자연스러운 한국어 발음으로 변환합니다. `9:16`과 타임코드는 음성에서 읽지 않습니다.

## 제품 크기

상품 상세페이지의 크기·무게와 기준물(손, 소켓, 책상, 사람)을 조사하고, 영상 프롬프트에 실제 비율 유지 조건을 넣습니다. 장면마다 제품을 과도하게 확대하거나 축소하지 않으며, 제품 본체와 포장 크기를 혼동하지 않습니다.

세부 규칙은 `automation/voice-normalization-rules.json`을 기준으로 합니다.
