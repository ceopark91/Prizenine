# PrizeNine 자동화 초보자 매뉴얼

## 1. Vercel 프로젝트 열기

1. [Vercel 대시보드](https://vercel.com/dashboard)에 로그인합니다.
2. 목록에서 **본인이 배포한 프로젝트 카드**를 클릭합니다. 프로젝트 이름은 사람마다 다를 수 있습니다.
3. 왼쪽 메뉴에서 **Environment Variables**를 클릭합니다. 직접 주소를 입력할 때는 `https://vercel.com/<내 팀 이름>/<내 프로젝트 이름>/settings/environment-variables` 형식입니다.

## 2. 트리거 키 등록

1. 오른쪽 위 **Add Environment Variable** 클릭
2. Type은 **Secret** 선택
3. Key에 `TRIGGER_SECRET` 입력
4. Value에 GUI의 트리거 비밀키 입력
5. Environments에서 **Production** 선택 후 Save
6. 같은 방법으로 `INGEST_TOKEN`을 추가하고 Value는 같은 키를 입력

## 3. 재배포

환경변수는 새 배포부터 적용됩니다. 왼쪽 **Deployments** → 가장 최근 배포의 `...` → **Redeploy**를 클릭합니다.

## 4. 상품 링크 테스트

1. `자동화-설정-실행.bat`을 더블클릭합니다.
2. 트리거 비밀키를 입력하고 **설정 저장**을 누릅니다.
3. 아래 URL 칸에 상품 링크를 붙여 넣습니다.
4. **테스트 실행**을 클릭합니다.
5. `202` 또는 `테스트 성공`이 나오면 정상입니다.

## 5. Google Sheets 연결(선택)

스프레드시트 편집 주소가 아니라 Apps Script 웹앱 주소(`/exec`)를 입력해야 합니다. 배포 후 주소는 `https://script.google.com/macros/s/.../exec` 형태입니다.

## 오류별 해결

- `401 권한 없음`: GUI 키와 Vercel의 `TRIGGER_SECRET` 값이 다릅니다.
- `Google Sheets 전달 실패`: Apps Script URL이 잘못됐거나 웹앱 액세스 권한이 제한돼 있습니다.
- 환경변수가 보이지 않음: 올바른 프로젝트를 열었는지 확인하세요.
