# PrizeNine 자동화 인수인계 규칙

## 영상 구성

- 상품 상세페이지에서 실제 상품 이미지 3~6장을 먼저 확보한다.
- 이미지는 제품 외형·색상·버튼·구성품을 고정하는 레퍼런스다.
- 대표 이미지만 단순히 움직이는 영상으로 만들지 않는다.
- 고정 캐릭터 `명예모델1호`가 상품에 맞는 사용 상황에서 제품을 들고 설명한다.
- 씬마다 모델 동작, 카메라 구도, 제품 사용 장면, 한국어 대사와 자막을 작성한다.
- 실제 이미지 레퍼런스를 사용하므로 `text_to_video`로 제품 외형을 새로 추정하지 않는다.

## 영상 구성 비율

- 0~4초: 짧은 후킹
- 4~28초: 장점과 실제 사용 장면 중심
- 28~35초: 구매 전 확인사항을 1~2문장으로 완곡하게 안내
- 마지막: 제휴 고지와 제품번호 CTA

## 마지막 CTA 고정 문구

제품번호는 상품목록 시트의 ARRAYFORMULA가 부여한 번호를 사용한다. 번호를 임의로 만들거나 A열에 직접 쓰지 않는다.

```text
제품이 궁금하시면 프로필 상세 링크에서 {제품번호}번을 검색해보세요.
```

예: `제품이 궁금하시면 프로필 상세 링크에서 18번을 검색해보세요.`

## 이미지 확보 실패 처리

1. 이미지 URL 직접 다운로드
2. 차단되면 브라우저에서 상품 이미지 영역만 캡처
3. 2장 이상 확보하면 여러 이미지 레퍼런스로 영상 생성
4. 1장만 확보하면 제한 사실을 기록하고 진행
5. 이미지가 전혀 없으면 영상 생성을 시작하지 않고 실패 처리

## 상태 처리

영상 생성 성공 및 결과 URL을 확인한 후에만 Apps Script `complete`를 호출한다. 실패 시 `fail`만 기록한다. 변경 없는 `pending`/`running` 상태는 알리지 않고, 성공·실패만 Codex 알림으로 전달한다.

## 번호가 1000번대로 나올 때

A열만 지우면 안 된다. 아래쪽에 남은 B~F 상품 데이터가 있으면 ARRAYFORMULA가 그 행까지 번호를 계산한다. 상품목록 시트에서 실제 상품이 아닌 아래쪽 행의 B~F를 함께 비운 뒤, Apps Script를 새 버전으로 재배포한다. 새 코드는 아래쪽 잔여 데이터가 있어도 연속 목록의 첫 빈 행에 기록한다.
