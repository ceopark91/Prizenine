# 다른 컴퓨터에서 PrizeNine 자동화 시작하기

## 준비

- Windows PC에 Codex 설치 및 로그인
- Topview MCP 로그인/권한 승인
- 이 저장소 다운로드: `https://github.com/ceopark91/prizenine.git`

## 1. GUI 설정기 실행

저장소 폴더에서 `START-AUTOMATION.bat`을 더블클릭합니다. 현재 운영 중인 설정값을 입력합니다.

- Google Apps Script URL: `https://script.google.com/macros/s/AKfycbw1L5eOZORf414Al_Epn-MaDjRNR9MTY5NOmttazxGDwKA7PO0PNGq4oRSIdDjBJvgDlw/exec`
- 트리거 비밀키: 운영 PC와 같은 키(공개하지 않음)
- 이메일/텔레그램 값: 본인 알림 계정 값

`설정 저장`을 누르면 PC에만 `.env.local`이 만들어집니다. 이 파일은 복사하거나 GitHub에 올리지 않습니다.

## 2. 상품 입력

Google Form: `https://docs.google.com/forms/d/e/1FAIpQLSc1v3DMjqOeaLAJ6A_a0VAo3A0nY6W6jCI8WbVuywyQdP08PA/viewform`

폼에 상품 URL을 제출하면 Apps Script가 `_queue`에 `pending`으로 저장합니다.

## 3. Codex 자동화

Codex에서 `automation/codex-worker-prompt.md` 내용을 사용해 5분 주기 자동화를 만들고 활성화합니다. PC가 켜져 있고 Codex가 실행 중이어야 합니다.

## 상태 확인

Apps Script 주소 뒤에 `?action=pending`을 붙여 열면 대기 작업을 볼 수 있습니다. `_queue`의 상태는 `pending → processing → done`이며, 오류 시 `failed`입니다.

## 주의

Vercel 프로젝트는 고객/컴퓨터마다 다를 수 있지만, Codex worker가 사용하는 Apps Script URL과 Topview 계정은 해당 운영자 것으로 설정해야 합니다. 비밀번호는 저장하지 말고 OAuth·토큰을 사용합니다.
