# PrizeNine 초기 설정 도우미

프로젝트 폴더를 다른 컴퓨터에 복사하고 `START-HERE.bat`을 실행하면 설정 도우미가 시작됩니다.

## 설정 도우미가 물어보는 순서

### 1. Google Apps Script

도우미가 `docs/google-apps-script.gs` 파일의 전체 코드를 보여주고, 사용자가 Google Sheets에서 다음 순서로 붙여넣도록 안내합니다.

1. Google Sheets 열기
2. 확장 프로그램 → Apps Script
3. 기존 코드 전체 삭제
4. `google-apps-script.gs` 전체 붙여넣기
5. 저장
6. 배포 → 새 배포 → 웹 앱
7. 실행 사용자: 본인
8. 액세스 권한: 모든 사용자
9. 나온 `/exec` 주소를 도우미에 붙여넣기

도우미는 주소가 정상 응답하는지 자동 테스트합니다.

### 2. 기본 연결

- Google Form 주소
- Google Sheet 주소
- 완료·실패 알림 이메일

### 3. Topview 연결

Topview 로그인 창을 열고 사용자가 OAuth 인증을 완료하면 도우미가 MCP 연결을 확인합니다.

### 4. 캐릭터 설정

사용자가 원하는 캐릭터 외형과 분위기를 문장으로 입력합니다. 예를 들어 `30대 한국 여성, 밝고 신뢰감 있는 생활용품 리뷰어`처럼 적습니다.

도우미는 Topview에서 캐릭터를 생성하고, 생성 전에 크레딧 사용 여부를 확인합니다. 생성 후 캐릭터 토큰을 자동 저장합니다.

### 5. Canvas 설정

Canvas 주소를 모르면 도우미가 새 Canvas를 생성합니다. 세로형 리뷰 기본 레이아웃과 캐릭터를 자동으로 배치하고 Canvas ID와 URL을 저장합니다.

### 6. 테스트

최근 상품 주소 또는 사용자가 붙여넣은 상품 주소로 테스트합니다.

- 실제 상품 이미지 3~6장 확보
- 상세 설명·공개 리뷰 분석
- 모델과 사용 상황 중심 스토리보드 작성
- image_to_video 생성
- 마지막 CTA: `제품이 궁금하시면 프로필 상세 링크에서 {제품번호}번을 검색해보세요.`
- 성공 시 이메일·Codex 알림

## 생성되는 로컬 설정

도우미는 사용자 답변으로 `CONFIG.local.md`와 `.env.local`을 자동 생성합니다. 비밀값은 GitHub에 올리지 않습니다.

## 사용자가 직접 입력하는 항목

Google Apps Script `/exec` 주소, Google Form 주소, Google Sheet 주소, 알림 이메일, Topview 로그인, 캐릭터 설명입니다. Canvas는 모르면 자동 생성합니다.
