# PrizeNine 자동 영상 작업자 지침

최신 Google Apps Script 주소의 `?action=pending`을 확인하고, pending 작업은 먼저 `action=claim`으로 확보한다. 상품 URL을 실제 브라우저에서 열어 상품명·브랜드·설명·가격·공개 리뷰와 실제 상품 이미지 2~4장을 확보한다. 원본 이미지가 세로로 길면 제품 외형을 재생성하지 말고 원본 픽셀을 기계적으로 패딩/리사이즈한다.

## 판매 영상 구성

- 기본 길이: 30~45초. 15초는 명시적인 테스트 모드일 때만 허용한다.
- 0~3초: 문제 상황 또는 강한 후킹 장면
- 3~10초: 실제 상품 정면/디테일 클로즈업과 핵심 기능
- 10~24초: 고정 캐릭터가 실제 사용하고 전후 상황을 보여주는 킬링 인서트 2~3개
- 24~34초: 공개 리뷰에서 반복 확인된 장점과 적합한 사용자
- 34~40초: 구매 전 확인사항을 짧고 정직하게 안내
- 마지막 4~5초: `프로필 링크에서 제품번호 N번을 검색해 주세요` 문구와 제품번호를 화면·음성으로 명확히 표시하고 제휴 고지를 포함

Topview Canvas에서는 실제 상품 이미지 여러 장과 고정 캐릭터를 함께 참조해 image-to-video로 생성한다. text-to-video로 제품 외형을 추정하지 않는다. 킬링 인서트는 상품을 구매하고 싶게 만드는 구체적 사용 장면(문제 발생→제품 사용→개선)을 우선한다. 영상 파일과 결과 URL을 검증한 뒤에만 Apps Script `action=complete`를 호출하고, 실패 시 `action=fail`과 원인을 기록한다.

## 크기·비율 정확성

상품의 실제 가로·세로·높이 비율과 손, 책상, 냉장고 등 주변 기준물과의 상대 크기를 유지한다. 제품을 실제보다 크게 보이게 하거나 작게 축소하지 않는다. 크기 정보가 확인되지 않으면 제품 상세페이지의 치수 표기와 실제 이미지 속 기준물을 우선하고, 불확실한 경우 과장된 원근·클로즈업을 피한다. 모델이 제품을 들거나 사용하는 장면에서도 손 크기와 제품 비율이 장면마다 일관되게 유지되어야 한다.
