# 사용자가 입력할 명령어

처음에는 Codex에서 이것만 입력합니다.

```text
세팅해
```

이후 Codex가 필요한 순간에만 사용자에게 요청합니다.

- Google 로그인·권한 승인 버튼 클릭
- Topview 로그인·OAuth 승인 버튼 클릭
- 상품목록으로 사용할 Google Sheet 선택 또는 주소 붙여넣기
- 완료 알림 이메일 입력
- 원하는 캐릭터 설명 입력(선택)

그 외 작업은 Codex가 처리합니다.

## 자동 처리 항목

- Apps Script 코드 준비 및 `setupSystem` 실행 안내
- Google Form 생성 확인
- `_queue`와 상품목록 구조 확인
- 제품번호 ARRAYFORMULA 확인
- Topview MCP 연결 확인
- Canvas 자동 선택 또는 생성
- 캐릭터 생성·등록
- Vercel 환경변수 안내
- 최근 상품으로 테스트
- 성공·실패 결과 보고
