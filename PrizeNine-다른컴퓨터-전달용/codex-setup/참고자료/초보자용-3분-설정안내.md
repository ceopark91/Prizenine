# 처음 사용하는 분용 — 3분 설정

## 1. 폴더 복사

받은 `탑뷰프로젝트` 폴더를 컴퓨터 바탕화면에 복사합니다.

## 2. 설정 파일 열기

`codex-setup` 폴더에서 `사용자-설정만-수정.md` 파일을 엽니다.

파일을 **다른 이름으로 저장**하고 파일 이름을 정확히 `CONFIG.local.md`로 입력합니다.

## 3. 본인 정보만 입력

아래 3개만 본인 것으로 바꿉니다.

```text
GOOGLE_FORM_URL=구글폼_주소_붙여넣기
SHEET_URL=구글시트_주소_붙여넣기
NOTIFY_EMAIL=알림받을_이메일_입력
```

주소는 크롬 주소창에서 복사해 붙여넣으면 됩니다. `=` 앞부분은 지우거나 바꾸지 않습니다.

## 4. 저장

`Ctrl+S`를 눌러 저장합니다.

## 5. 실행

`codex-setup` 폴더의 `START-HERE.bat`을 **더블클릭**합니다.

검은 창이 잠깐 열리고 자동화가 시작됩니다. 오류가 나오면 오류 문장을 그대로 보내주세요.

## 사용자가 입력하지 않는 값

아래 값은 이미 연결되어 있으므로 건드리지 않습니다.

- Apps Script 주소
- Topview Canvas 주소
- 고정 모델 `명예모델1호`
- 제품번호 규칙

## 보안 주의

`CONFIG.local.md`와 `.env.local`에는 비밀번호와 API 키가 들어갈 수 있습니다. 이 파일은 GitHub에 올리거나 다른 사람에게 공개하지 않습니다.
