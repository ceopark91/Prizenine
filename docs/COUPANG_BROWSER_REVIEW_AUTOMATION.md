# 쿠팡 공개 리뷰 기반 영상 자동화

## 원칙

영상 자동화에서 쿠팡 리뷰는 서버에서 쿠팡으로 직접 요청하지 않는다. 사용자가 열어 둔 브라우저 세션에서 로그인 없이 공개되어 있는 상품 정보와 리뷰만 읽고, 그 결과를 분석 API로 전달한다. 로그인, CAPTCHA 해결, 숨은 API 호출, 차단 우회, 구매자 개인정보 수집은 자동화 범위에 포함하지 않는다.

이 방식은 상품 페이지의 공개 리뷰 영역이 보이는 경우에만 동작한다. 리뷰 영역이 로딩되지 않거나 봇 확인/차단 화면이면 수집을 중단하고 URL·상품 정보만으로 진행하거나 사용자의 확인을 요청한다.

## 표준 payload

```json
{
  "url": "https://www.coupang.com/vp/products/7423817768",
  "source": "browser-session",
  "product": {
    "title": "상품명",
    "rating": 4.2,
    "reviewCount": 419,
    "summaryMetrics": {
      "design": 64,
      "comfort": 65,
      "sound": 52,
      "value": 66
    }
  },
  "reviews": [
    {
      "id": "review-1",
      "text": "사용하기 편하지만 소음이 있어요.",
      "rating": 4,
      "date": "2025-03-26",
      "sourceUrl": "https://www.coupang.com/vp/products/7423817768"
    }
  ]
}
```

## 처리 흐름

1. 브라우저 세션에서 상품 URL을 연다.
2. 공개 상품명·평점·리뷰 수·요약 지표·현재 보이는 리뷰를 읽는다.
3. `POST /api/research`에 `url`, `product`, `reviews`를 전달한다.
4. 개별 리뷰의 감성·주제·근거 문장을 분석한다.
5. 반복 장점·단점과 불확실성을 영상 프롬프트에 반영한다.
6. 영상에는 리뷰 기반 주장임을 표시하고, 가격·배송·성능을 근거 없이 확정하지 않는다.

## 영상 프롬프트 규칙

- 긍정 리뷰만 모아 광고 문구로 만들지 말고 반복되는 단점을 함께 반영한다.
- 단일 리뷰의 경험은 “일부 리뷰에서”로 표현한다.
- 3건 미만의 동일 불만은 제품 전체의 결함으로 단정하지 않는다.
- 평점·리뷰 수·요약 지표는 수집 시점과 함께 저장한다.
- 작성자명, 판매자 연락처 등 개인정보는 저장·영상화하지 않는다.

## API 구분

- `POST /api/research`: 브라우저 세션 리뷰를 분석한다.
- `POST /api/ingest`: 영상 자동화 큐와 Google Sheets 전달용이다. `reviews`가 있으면 최대 100건까지 브라우저 세션 원천으로 표시한다.
- 서버가 쿠팡 URL만 직접 요청하는 자동 수집은 403 시 중단하고 `browser-session` 경로로 전환한다.
