# 사용자 설정 — 아래 3곳만 입력하세요

이 파일에서 `입력하세요`라고 적힌 부분만 바꿉니다. 다른 줄은 수정하지 않습니다.

## 1. 구글폼 주소

구글폼을 열고 주소창의 주소를 복사해 붙여넣습니다.

```text
GOOGLE_FORM_URL=여기에_구글폼_주소를_붙여넣으세요
```

## 2. 구글시트 주소

상품목록이 있는 구글시트를 열고 주소창의 주소를 복사해 붙여넣습니다.

```text
SHEET_URL=여기에_구글시트_주소를_붙여넣으세요
```

## 3. 알림 받을 이메일

```text
NOTIFY_EMAIL=여기에_알림받을_이메일을_입력하세요
```

## 아래 공용 설정은 수정하지 마세요

```text
GOOGLE_APPS_SCRIPT_URL=https://script.google.com/macros/s/AKfycbw1L5eOZORf414Al_Epn-MaDjRNR9MTY5NOmttazxGDwKA7PO0PNGq4oRSIdDjBJvgDlw/exec
TOPVIEW_CANVAS_URL=https://www.topview.ai/canvas/51f28b21ca1e497fa6a8589c3f8fdbb8
TOPVIEW_CANVAS_ID=51f28b21ca1e497fa6a8589c3f8fdbb8
TOPVIEW_CHARACTER_NAME=명예모델1호
TOPVIEW_CHARACTER_TOKEN=<<@char_1>>
```

## 저장과 실행

1. 이 파일을 `CONFIG.local.md`로 저장합니다.
2. `Ctrl+S`를 누릅니다.
3. `codex-setup` 폴더의 `START-HERE.bat`을 더블클릭합니다.

`=` 앞의 글자는 지우지 말고, 주소는 전체를 붙여넣습니다. `CONFIG.local.md`는 GitHub에 올리지 않습니다.
