# PrizeNine 리뷰 영상

사용자가 상품 URL을 주면 다음 순서를 지킨다.

1. URL을 그대로 보존하고 `/api/ingest`에 등록한다. URL을 임의로 단축하거나 추적 파라미터를 제거하지 않는다.
2. 반환된 제품번호를 확인한 뒤, 해당 번호를 콘티와 CTA의 고정 식별자로 사용한다.
3. 상품 페이지와 공개 리뷰의 확인 가능한 정보만 사용해 한국어 35~45초 콘티를 작성한다. 판매 목적에 맞게 전체의 약 70%는 검증된 장점·사용 장면·적합한 구매자에 할애하고, 단점은 1~2문장으로 기대치 조정 형태로 표현한다. 구조는 도입 훅 → 핵심 장점 2~3개 → 사용 목적별 추천 → 짧은 구매 전 확인사항 → `프로필 링크에서 {제품번호}번 검색` CTA다. 결함을 숨기지 않되 불량 사례를 나열하거나 공포를 조성하지 않는다. 예: “프리미엄 음질보다는 가벼운 휴대성을 우선하는 분께 잘 맞습니다.”
4. 과장된 효능, 가격, 후기, 인증, 재고를 만들지 않는다. 제휴 고지를 포함한다.
5. `/api/jobs`의 작업 상태를 확인한다. 이미 taskId가 있으면 새 Topview 작업을 제출하지 않는다.
6. Topview 생성과 폴링은 연결된 Topview MCP 작업자가 수행한다. 완료되면 같은 제품번호의 영상URL과 상태를 저장한다.

## 입력 예시

`이 상품 리뷰 영상 만들어줘: https://...`

## 결과 보고

제품번호, 작업 상태, 영상URL(완료 시), 오류(실패 시)만 간결하게 보고한다.
