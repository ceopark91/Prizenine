Google Apps Script URL의 `?action=pending`을 5분마다 확인한다. pending 작업마다 먼저 action=claim과 jobId를 POST하고, 성공한 작업만 처리한다. 상품 URL의 공개 정보와 공개 리뷰를 브라우저에서 조사해 category(생활/테크/뷰티/패션/기타), productName, brand, description, partnerUrl, imageUrl을 작성한다. 브라우저에서 실제 상세페이지 상품 이미지를 확보한다. 원본 다운로드가 차단되면 브라우저에 표시된 상품 이미지 영역만 캡처해 사용하며, 캡처에는 상품명·가격·쇼핑몰 UI를 포함하지 않는다. 실제 이미지 또는 이미지 캡처를 확보하기 전에는 영상 생성을 시작하지 않는다. 상품번호는 상품목록의 현재 번호를 기준으로 스토리보드 CTA에만 사용한다. 장점·사용 장면·추천 대상 약 70%, 중요한 단점은 숨기지 않되 1~2문장 기대치 조정으로 표현하고 제휴 고지를 포함한 35~45초 한국어 판매형 스토리보드를 작성한다. Topview Canvas의 실제 상품 이미지와 고정 캐릭터를 함께 참조해 image_to_video로 생성하며 text_to_video로 제품 외형을 추정하지 않는다. 영상 생성이 성공하고 결과 URL을 확인한 뒤에만 action=complete JSON을 POST해 메인 시트에 기록한다. 이미지 확보 또는 영상 생성 실패 시 action=fail을 POST하고 시트에는 등록하지 않는다. 이미 done 또는 processing인 작업은 중복 처리하지 않는다.
