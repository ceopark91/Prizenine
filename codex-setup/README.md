# 다른 PC용 Codex 실행 폴더

이 폴더만 내려받아도 초보자가 설정 위치를 찾을 수 있습니다.

## 먼저 읽을 문서

- `CONFIG.template.md`: 사용자별 주소와 변수
- `다른컴퓨터-설치순서.md`: 최초 설치 순서
- `브라우저-작업-프롬프트.md`: 자동화 규칙

## 시작

1. 상위 폴더의 `START-AUTOMATION.bat`을 더블클릭합니다.
2. Google Form에 상품 URL을 제출합니다.
3. Codex에서 `브라우저-작업-프롬프트.md`를 새 자동화 작업 지침으로 사용합니다.
4. Codex가 PC 브라우저에서 상품 페이지를 열고 공개 상품정보·리뷰를 읽습니다.

쿠팡·테무·알리처럼 서버 요청을 차단할 수 있는 사이트는 반드시 로그인된 PC 브라우저 세션에서 열어야 합니다. 비밀번호는 Codex나 파일에 저장하지 않습니다.

## 작업 상태

Google Apps Script의 `_queue`에서 `pending → processing → done/failed`로 확인합니다.
